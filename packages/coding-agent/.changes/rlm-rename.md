- Added the `rlm.rename(new_name, session_id=...)` kernel function: renames the calling session (no `session_id`) or a direct child selected by spawn handle, `list_subagents()` row, or session id — never by child name — reusing spawn-name validation and sibling uniqueness; the renamed session gets a `Session renamed \`old\` -> \`new\`` transcript notice (suffixed \` by parent\` when a parent renamed it), and the kernel readiness check now requires a runtime with `rlm.rename`.
- Agents view: the rename affordance (ctrl+r / `/name`) now also applies to subagent rows, which carry the same renameable session identity as top-level agent rows.
