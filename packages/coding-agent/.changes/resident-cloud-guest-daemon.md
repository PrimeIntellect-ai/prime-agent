- Added the resident guest daemon for cloud sessions: the uploaded bridge now supervises a real `--mode daemon` session runtime in the sandbox instead of running one-shot `--print` tasks, delivers the scoped inference credential to it as `PRIME_API_KEY` without logging it, and always owns the terminal results contract.
- Hardened the guest session log: acknowledged history trims without fencing reconnecting clients (a stale cursor resyncs from a snapshot, and a trim that retains more than one snapshot page drains the remaining pages gap-free instead of reporting an undelivered tail), a full log with no acknowledgements stalls mirroring honestly (surfaced in the daemon's status record) instead of crashing, and oversized or split-multibyte protocol frames are handled within bounded buffers.
- Extended the cloud session protocol to v2 with ordinary session operations (prompt, steer, follow-up, abort, model/thinking/name, compact, child ops, messages, release), durable session entry mirroring with artifact refs, live session events, roster and usage streams, and a version gate that rejects v1 clients and commands with typed errors.
- Extracted the daemon worker's session-host core (runtime binding, roster composition, lazy hydration) into a reusable seam shared with the resident guest daemon.
