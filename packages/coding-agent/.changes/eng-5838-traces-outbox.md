- Reworked agent-trace upload scheduling as a disk-cursor outbox: upload intent and per-session uploaded-content cursors persist in `agent-traces-outbox.json` in the agent dir, a startup catch-up uploads anything a previous process never finished (pruning cursors of deleted session files), unchanged sessions are never re-uploaded, and rate-limited uploads reschedule instead of sleeping. Session disposal and process exit no longer wait on trace uploads at all; the exit drain barrier is gone (the startup catch-up replaces it).
