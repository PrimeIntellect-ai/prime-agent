- Cached kernel bootstrap validation for the process lifetime: sequential kernel starts reuse a validated venv instead of re-running the ready-check interpreter probe on every start. The entry is keyed by env + python-skill hashes + runtime identity (both hashes are still computed per start, so source and skill edits keep invalidating it) and guarded by the bootstrap marker's stat identity; failures, and a skill sync that left a skill uninstalled, leave no entry so the next start revalidates.
