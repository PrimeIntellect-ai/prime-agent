- Fixed a daemon that could never start again after its supervisor was left unreaped: a zombie process still answers `kill(pid, 0)`, so the supervisor ownership registry treated the dead generation as the live owner and failed every launch with `DaemonSupervisorAlreadyRunningError`. Liveness probes across the supervisor registry, session leases, the supervisor launch lock, update-restart coordination, `status`/`doctor`, and the kernel bootstrap lock now all exclude zombies.
