- Added end-to-end swarm workflow tests over the real kernel bridge: a real AgentSession with a real Python kernel, seeded local harness state, real in-process child sessions spawned through the `rlm.run` host path, and a scripted model closes the fake-host gap (a missing host handler or a drifted payload used to pass silently). Scenarios cover a guarded review/fix loop machine with optional-input re-binding, fan-out diamond with join, escalate pause resumed to completion, stop() cancelling running children through the real delete path, a dag-form spec compiled and run through the same bridge, and run() returning before any child settles with the milestone landing later as its own wake turn. The suite pins the kernel to an isolated checkout venv (PRIME_AGENT_KERNEL_PYTHON or prime-agent-runtime/.venv); when neither is usable it fails fast instead of letting the standard bootstrap rebuild a live shared kernel venv, and only boots through the standard bootstrap when no shared venv pre-exists (CI pre-warms it via bootstrap-cli).
