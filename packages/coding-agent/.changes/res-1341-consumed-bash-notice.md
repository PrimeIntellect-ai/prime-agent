- Background command completion notices are now withdrawn when the kernel reads the result first: a `bash()` handle whose finished result is read (awaited, polled, or read via `output()`/`tail()`) no longer produces a "Background command finished" follow-up message, and a notice that is still queued is removed instead of delivered. Unread completions are delivered as before, and the queue and transcript label for them is now "Background command finished" instead of "Shell message received".
