- ACP `session/steering` (the nano-rlm #205 extension, ported): clients can inject a user message into a running turn without cancelling in-flight tools. `initialize` advertises `_meta.steering.supported`; the request answers `{"outcome": "injected"}` while a prompt turn runs and `{"outcome": "queued"}` on an idle session, where the message runs as the next turn (a declared divergence from nano-rlm's `promptRequired`).
