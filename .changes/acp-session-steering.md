- ACP `session/steering` (the nano-rlm #205 extension, ported): clients can inject a user message into a running turn without cancelling in-flight tools. `initialize` advertises `_meta.steering.supported`; the request answers `{"outcome": "injected"}` while a prompt turn runs and `{"outcome": "queued"}` on an idle session, where the message runs as the next turn (a declared divergence from nano-rlm's `promptRequired`).
- ACP steering review fixes: the `injected`/`queued` receipt maps from the worker's own busy flag at the enqueue (the `steer`/`follow_up` response now carries `busy`) ANDed with the ACP turn slot, so neither side's race window lies; `session/cancel` with no prompt turn slot still arms the stop sequence for admitted steered work — the steered-work flag is set at the admission point (before the worker round trip) and only a completed stop sequence clears it, so a cancel racing the admission or a prompt that fails after its own admission cannot orphan a running steered turn; a steer whose admission races an armed cancel is withdrawn (re-issued `abort_and_clear_queue`) and answered with the cancelling refusal.
