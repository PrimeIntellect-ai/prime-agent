- Added the guest-side idle self-pause for bots: a bot's guest daemon asks the always-on relay (the `bots.relay.url` setting; off when unset) to pause its own sandbox after `bots.selfPauseMinutes` idle minutes (default 10, `0` disables it), so a bot stops billing when the owner's machine is offline. Idle means no running turn, no attached client, and no inbound message; the relay holds the platform key and the bot's per-bot token rides a header rule scoped to the relay's host, so no Prime API key ever enters the sandbox. A resume continues the guest daemon with its sessions intact and the timer re-armed, and the owner's daemon treats a sandbox the guest paused like any paused bot (no double pause, boot reconcile leaves it alone).
