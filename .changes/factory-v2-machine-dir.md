- Factory machines can be directories with a `machine.toml` graph, typed inputs and outputs, Markdown prompts, rubrics, and Python states. `prime-agent factory validate` checks a directory, `factory compile` prints its canonical spec, and `factory convert` converts a supported `MACHINE.md` machine. `factory list` and `rlm.factory.run('<name>')` find both kinds of machine through one library scan, and `factory list` no longer starts a Python process.
