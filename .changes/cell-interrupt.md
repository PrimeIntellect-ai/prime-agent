- A `python_repl` cell that runs past its time limit is now interrupted instead of only getting a note afterwards. The model sees an error that names the limit and explains how to move long work into asyncio tasks; variables survive. If the cell ignores the interrupt, the kernel is restarted. The model can set a per-call `timeout` (seconds, max 180); the default stays 60 s (`pythonCellTimeoutMs`, `0` disables).
