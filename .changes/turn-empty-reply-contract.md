- A turn that ends with no visible answer (a blank reply, or thinking blocks with only a `(no action)` stub) no longer ends silently: on a prompt the user typed, the session injects one retry prompt asking the model to reply again with its complete answer as ordinary text (shown in the TUI as a `↻ Retry prompt` row), and a second empty reply fails the turn with a visible error that suggests resending the message or switching models. Machinery-woken turns (agent messages, continuations, notices) keep their settled reply and never get the retry.
