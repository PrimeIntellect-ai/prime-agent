- Key bindings can now use Ctrl, Alt, Shift, or Super with Enter, Tab, Esc, and Space, and Ctrl or Alt with Backspace (for example `ctrl+enter`, `ctrl+tab`, `ctrl+space`, or `ctrl+alt+backspace`). Before, a `ctrl+space` binding never matched, and in terminals that report these chords the TUI dropped some modifiers: Ctrl+Enter submitted like Enter, Ctrl+Tab autocompleted like Tab, and a modified Esc acted as Esc. Such a chord with no binding now does nothing. To keep an old action, add the chord to that binding in `~/.prime/agent/keybindings.json`, for example `"tui.input.submit": ["enter", "ctrl+enter"]`.
