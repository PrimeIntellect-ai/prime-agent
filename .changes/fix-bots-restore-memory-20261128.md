- Fixed bots failing to come back after their paused sandbox ended: the platform now restores a pause checkpoint only with its memory, so a bot's restore create sends `restore_memory` when the checkpoint holds memory (and retries with it under a fresh idempotency key when the platform's refusal says it must), instead of every wake failing with "Sandbox create returned a conflict (HTTP 409); this is typically transient". Sandbox create conflicts now carry the platform's reason.
