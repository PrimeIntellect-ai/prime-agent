- A backgrounded Python cell that runs synchronous code no longer deadlocks the session: the `KernelBusy` refusal names the cell that holds the kernel and says to retry with `cancel_background: true`, and `python_repl`'s new `cancel_background` field stops that cell through the same scoped cancel the UI's idle stop key sends (a cell that ignores the interrupt has its kernel retired, losing unsnapshotted state) before running the call's own code.
