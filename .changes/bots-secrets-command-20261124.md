- Added the `/secrets` command: one view, like `/mcp`, that lists every secret bots can get (API keys, logins, GitHub, MCP logins, and custom secrets) with its status and hosts. Turn a secret off for bots (`bots.inject.<name>`), add a custom secret for an HTTPS host with a Bearer, Basic, or custom header (the value is typed once, masked, and kept in the Mac auth storage), or remove one. The view enforces the platform limits, and changes reach running and paused bots through a network policy update. Secret values never enter a bot.
