- Every HTTPS client surface (the model providers, the subscription OAuth flows, the proxy transport, the codex WebSocket transport, update/release checks, trace upload, Prime Inference auth and catalog, MCP connections, telemetry, the model catalog fetch) now honors custom certificate authorities: `NODE_EXTRA_CA_CERTS` appends a PEM file of extra CAs to the native/system roots (the TS build inherited this variable from the Node runtime), and `SSL_CERT_FILE`/`SSL_CERT_DIR` replace the root store per the OpenSSL convention. A variable that names a missing, unreadable, or invalid file fails loud with the variable and path instead of silently ignoring it; an unset variable changes nothing. Connections to internal servers with custom CAs work after exporting `NODE_EXTRA_CA_CERTS=/path/to/ca.pem`.
