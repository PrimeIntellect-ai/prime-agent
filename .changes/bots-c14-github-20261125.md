- Added GitHub access for bots: a bot's git and `gh` reach GitHub with the owner's token through Prime header rules, and the token never enters the sandbox. `prime-agent bots github set|clear|status` manages the token (the `gh` CLI login is the fallback), `bots.github` and `rlm.spawn(..., github=False)` turn it off, and bots commit as the owner's git author (`bots.gitIdentity` overrides it).
