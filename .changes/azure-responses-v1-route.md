- Azure OpenAI Responses requests no longer fail with 404 on the v1 API: they now post to `<resource>/openai/v1/responses` with the deployment as the request's `model`, instead of a `/deployments/<name>/responses` route Azure does not serve. A non-v1 `AZURE_OPENAI_API_VERSION` (for example `preview`, or a dated version against a custom `/openai` base URL) is still sent as the `api-version` query.
