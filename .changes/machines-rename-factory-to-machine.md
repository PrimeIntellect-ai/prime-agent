- Breaking: "machine" replaces "factory" in every user-facing name. The CLI command is `prime-agent machine list|validate|compile|convert|import|export`. The slash command is `/machine [on|off|status]`. The opt-in setting is `machine.enabled`; a stored `factory.enabled` is no longer read, so run `/machine on` once to turn machines back on. The kernel API is `rlm.machine` (`run`, `status`, `stop`, `resume`, `graph`, `watch`, `emit`, `inputs`, `help`), and a refused emit raises `MachineEmitError`. The bundled skill is `machine`. Inbox milestone notices use the `machine-progress` class, and `rlm.collect` results carry `machine_task_busy`.
