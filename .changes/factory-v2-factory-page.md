- The factory page lists every machine (bundled, personal, and machine directories) with this session's live runs nested under each, like the agents view. Open it from any session with the dock's factory group or a bare `/factory`, or from the agents view through the `app.agents.factory` key (unbound by default; Ctrl+F stays the message search); Enter on a machine shows its diagram, params, and its mermaid rendered as a diagram (never mermaid source text; a mermaid fence in a node's Markdown renders the same way, and types the page cannot draw collapse to a one-line placeholder), and Enter on a run opens its run page.
