- The factory page lists every machine (bundled, personal, and machine directories) with this session's live runs nested under each, like the agents view. Open it from any session with the dock's factory group or a bare `/factory`, or from the agents view through the `app.agents.factory` key (Ctrl+F by default; the message search `app.agents.searchContent` shares Ctrl+F and dispatches first, so unbind it to give Ctrl+F to the machines page); Enter on a machine shows its diagram, params, and its mermaid rendered as a diagram (never mermaid source text; a mermaid fence in a node's Markdown renders the same way, and types the page cannot draw collapse to a one-line placeholder), and Enter on a run opens its run page.
