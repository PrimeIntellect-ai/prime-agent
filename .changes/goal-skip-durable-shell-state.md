- A goal or `/autonomous` continuation now stays held behind a background `bash()` command even when the Python kernel is lost without graceful cleanup (a crash or hard kill): the gate reads the worker's durable orphan-process journal as well as the kernel's in-memory registry, so a shell that outlived its kernel still holds the continuation. The daemon watches that shell's exit through the operating system's process-exit notification (Linux and macOS) and resumes the held continuation when the shell actually exits, instead of minting through a live command whose completion notice died with the kernel. While an `/autonomous` continuation waits on that exit, the worker stays resident (idle eviction defers). The goal's five-minute fallback-wake message no longer promises a `[bash-done]` notification that an orphaned shell cannot send.
