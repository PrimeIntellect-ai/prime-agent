- Fixed kernel Python environment rebuilds deleting the live environment. A rebuild now builds beside the live environment and swaps it in when complete, so running sessions keep a working interpreter and a failed or interrupted rebuild leaves the previous environment in place. The replaced environment is renamed to `kernel-venv.stale-<timestamp>` during the swap, so an interrupted swap can restore it, and it is removed once the new environment is in place. One process builds while the others wait for its result. Pillow is now a default kernel package, so viewing images works after a rebuild. Tests refuse to rebuild the user's real `~/.prime/agent/kernel-venv`.
