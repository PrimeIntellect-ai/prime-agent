- Add a machine library page to the activity dock when the daemon enables the factory lane. It lists library machines with their description and source. Enter opens the selected machine's diagram and scrollable Mermaid text. Esc returns to the list, then closes the page. `rlm.factory.spec_to_mermaid(spec)` returns Mermaid text, and `rlm.factory.library_graph(name)` returns a library machine with its spec and diagram text.
