- The factory page gains the machine library view: the activity dock's `☰ machines` group (the factory group's neighbor, the same opt-in gate) lists every library machine with its description and source; Enter drills into one for its ANSI diagram and its copyable mermaid text, and Esc backs out.
- `rlm.factory.spec_to_mermaid(spec)` renders any factory spec as mermaid diagram text (a state machine as a `stateDiagram-v2` with its guarded edges, a dag as a `flowchart TB` with its `foreach` annotations), and `rlm.factory.library_graph(name)` answers one machine's fields with its rendering; the terminal has no graphics subsystem, so the library page ships the diagram plus the mermaid text — renderable in GitHub and previews — not in-page pixels.
