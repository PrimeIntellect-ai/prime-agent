- A backgrounded `python_repl` cell that runs blocking code no longer leaves the session stuck: the `KernelBusy` refusal names the cell that holds the kernel, and `python_repl`'s new `stop_cell` field stops only that cell (restarting the kernel if it ignores the interrupt) before running the call's code. The system prompt now recommends `await asyncio.sleep(...)` over `time.sleep(...)` for waits in a cell.
