- The A2A server mode (`--mode a2a`) ships: Prime Agent is reachable as an Agent2Agent 1.0 agent over the JSON-RPC binding — the public Agent Card, the task lifecycle (SendMessage/SendStreamingMessage/GetTask/ListTasks/CancelTask/SubscribeToTask), SSE streaming, and bearer auth (`PRIME_AGENT_A2A_TOKEN` or the `a2a.token` setting; with neither set the mode mints a per-run token into an owner-only file in the agent dir and prints its path at startup). The token gates the task routes, and clients must send the `A2A-Version: 1.0` header; the mode's settings and limits (`a2a.maxContexts`, `a2a.publicBaseUrl`) live in README.md.
- A daemon mode's first session lease in a fresh agent dir behind a symlinked path now persists on the canonical session path (the lease creates the session file's parent first), so TUI/ACP workers and print mode keep their first session instead of failing every append.
