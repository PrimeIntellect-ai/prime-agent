- ACP mode over the daemon now honors the session flags: without `--no-session` the conversation is saved like any other session and `--resume`, `--continue`, `--fork` and `--session-dir` open or place it; only `--no-session` sessions belong to the editor's connection and end when it disconnects, and `session/close` stops the running work without ending the session. Startup failures (an unknown or busy session) now exit with an error instead of starting, and `DO_NOT_TRACK` / the telemetry setting now also disable the daemon session's telemetry.
