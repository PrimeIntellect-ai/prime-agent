- The TUI now appends each settled turn's new transcript rows into the terminal's native scrollback, so `prefix [` (tmux copy mode) or plain terminal scrollback walks the conversation without opening the TUI viewport. The first settle after startup or a resume backfills the whole loaded transcript (matching the exit flush); later settles append only their new rows, and mid-run suspend cycles (Ctrl+Z, the external editor) never duplicate what they already wrote. Deliberate TS divergence: the TypeScript product has no equivalent feature. Gated by the new `terminal.scrollbackFlush` setting (default on) and the existing `PRIME_AGENT_TUI_EXIT_FLUSH=0` kill switch, and the row is toggleable in the TUI settings menu (Display tab).
