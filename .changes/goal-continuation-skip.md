- A goal continuation held behind live background work (a background `bash()` command or a backgrounded cell) now arms a fallback wake: if the work is still running five minutes after the goal goes quiet, one marker turn continues the goal (the completion notification still arrives separately when the work ends). The wake fires once per wait, not every five minutes, so hung work no longer stalls an active goal silently and a long build does not cost a model turn every window.
