- An await of a still-running `bash()` command now returns a snapshot that says what to do: the command runs in the background (pid, elapsed running time, snapshot time), do not await it again this turn; end the turn and collect the final result on the `[bash-done]` notification. The note now appears on every degrade instead of only the first three per session, and repeated snapshots show the elapsed growing, so a repeat-await loop becomes visible.
