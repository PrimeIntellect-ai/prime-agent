- Fixed fresh installs missing built-in skills: the installer now pre-installs the packaged Python skills (including `goal`) into the kernel venv, and the bundled `factory` skill no longer disappears from the skill list because of invalid frontmatter.
- Fixed the kernel venv's skill cache stranding a user override: when an installed Python skill is replaced by another source for the same import name (for example the installer pre-installing the packaged `goal` over a user's own `goal`), the stale cache record is now dropped, so the next session reinstalls the skill it actually discovered instead of importing the replaced code.
