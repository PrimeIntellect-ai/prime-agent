- The prompt editor turns emoji shortcodes into emoji as you type: `:heart:` becomes ❤️ when you type the closing colon, and typing `:` plus two letters (for example `:he`) lists matching emoji in the completion menu. Code spans, fenced code blocks, and text like `10:30` or `std::fmt` stay as typed. Turn it off with the `emojiShortcodes` setting or the Emoji shortcodes row in `/settings`.
