- A Python skill that failed to load into the kernel (for example after `PRIME_AGENT_KERNEL_PYTHON` points at a Python without the bundled skills) now raises `RuntimeError: Python skill <name> is unavailable in this kernel. Import error: ...` on any use, both through the pre-imported name (`goal.complete()`) and after `import goal`, instead of a bare `AttributeError` or `ModuleNotFoundError`.
