- `bash()` warns when a recursive search (`grep -r`, `rg`, or `find`) scans your home directory or a folder directly under it with no depth bound, since piping to `head` does not limit scan time. The warning covers named shapes and does not catch every spelling. Set the opt-in `PRIME_AGENT_SCAN_TIMEOUT` env var to a number of seconds to stop a matching plain command after that time; a command with a substitution, a function definition, or a heredoc gets the warning only, and the result keeps the partial output.
