- `rlm.spawn(kind="decision")` spawns a Decision API child served by the `decisionModel` setting: a JSON decision request (`seq`, `state`, `questions`, at most 4 `images`) comes back to the spawning agent as a tagged `decision_api.decision` agent-message follow-up carrying the request's `seq` (a request without one answers with `seq: null`), and a message that is not a request only readies the child ("Decision child ready.", no decision). Every reply costs the parent one model run: the follow-up row wakes an idle parent, a busy parent runs one extra turn per queued reply after its current turn, and a control-loop cell cannot read a reply until its turn ends; past 20 pending deliveries the reply send fails.
