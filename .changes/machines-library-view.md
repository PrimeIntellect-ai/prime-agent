- The factory page is now the machines page. It lists every machine: bundled, personal, and machine directories. Under each machine, it nests every session's active runs, with live state and progress. Rows that another session owns are read-only and name the session to open. Your session's 20 newest finished runs stay listed, and Enter opens their run page. Open the page from the dock's machines group, a bare `/factory`, or the agents view (`app.agents.factory`, Ctrl+F by default). Enter on a machine shows its diagram and params. A mermaid fence in a node's Markdown renders as a diagram, never as source text. Machines with a live run list first with a `◈` glyph, and quiet machines show a dim `•`. The dock shows one number, the running count (`1 machine`, `2 machines`). The agents view line keeps the full count: `⚙ N machines · M running`. `/factory` and the `factory.enabled` setting keep their names.
