- A child of a directory machine hands back its outputs with `await rlm.machine.emit(...)`. Each value is checked against the declared type before anything is kept, a wrong value raises `MachineEmitError` with the exact field, and `file` outputs are copied beside the child's session (a `file` inside a list or a record field, or a `file` output on a python state, is refused at load). `await rlm.machine.inputs()` gives the child its bound inputs and params.
- A foreach entry retries each instance that omitted a required output, not only the last instance to settle. A resumed entry re-admits every omitted instance.
