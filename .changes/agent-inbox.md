- agent inboxes — machine notices (bash completions, factory milestones) accumulate in a durable per-session inbox; a short coalesced steering notice and a periodic reminder announce them (the reminder never fires while `reminderIntervalMs: 0` or `agentInbox.enabled: false` is set); a bash handle collected through its result clears its own message; a journal write failure names its memory-only degradation in the notice; the journal replays complete records across a torn write and keeps message ids monotonic across restarts; the agent reads and drains the rest with rlm.inbox.read()/rlm.inbox.count()
